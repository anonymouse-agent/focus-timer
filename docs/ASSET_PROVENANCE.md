# Asset Provenance

## Character artwork

The avocado, cat, dog, and tomato artwork was made for Focus Timer with AI-assisted image generation, then selected, adjusted, converted for pixel display, and integrated into the app.

The assets are original to this project. They were not extracted from Tina Huang's Pixel Pomodoro app.

## App icon

The Focus Timer icon was made for this project and does not use third-party branding.

## External names

Tina Huang and Pixel Pomodoro are mentioned only to describe the product's inspiration. Focus Timer is an independent project and is not affiliated with or endorsed by Tina Huang.
